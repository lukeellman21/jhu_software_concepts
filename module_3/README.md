# Module 3: Database Queries, SQLAlchemy, and Dynamic Webpages

## Overview
This project establishes an end-to-end data engineering pipeline for The Grad Café dataset. It loads 30,000 scraped records into a PostgreSQL relational database, executes analytical reporting using both raw SQL queries and SQLAlchemy ORM, and serves an interactive web dashboard built with Flask.

## Prerequisites & Installation
- Python 3.10+
- PostgreSQL 16+
